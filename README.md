## 🎓 What's inside

- **6-week curriculum** — יסודות LLM → מודלים וכלים → פרומפטים → שילוב כלים → פרסום ופריסה → פרויקט אישי
- **19 lessons** with per-step practice checkboxes, completion tracking, real streak counter
- **Three themes** — System (mixed) · Light (Apple + Meta) · Dark (Runway + VoltAgent emerald)
- **Workshop view** — 3-panel code · run · explain
- **Cmd+K palette** · A11y-first navigation · Hebrew RTL with logical CSS properties
- **localStorage persistence** — progress survives reloads, days, weeks
